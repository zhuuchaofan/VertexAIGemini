桌面端

三栏：会话列表、对话、可开合的检视器。默认只有前两栏。检视器用「运行」和「设置」两个标签，不做常驻参数表。

画布 1280×800，按窗口宽度缩放

移动端

单栏。会话列表是左侧抽屉；模型在标题下方一点即选；思考与联网是输入框上的两个胶囊；其余设置和运行详情都是底部面板或整页。

关键交互状态

每张卡片先写「规则」，再给画面。规则来自后端实际能提供的信息：没有证据的内容不显示。

设置分层与重新生成的数据语义

下面是视觉稿所依据的语义，实现方案阶段会再展开成接口与 Firestore 字段。

请你确认的视觉决策

  1. 色调：冷灰蓝底加钴蓝强调色，深浅两套主题。可以改为偏中性灰或带一点暖色，但避免奶油底加陶土橙的常见组合。
  2. 控件位置：模型、思考、联网固定在输入框下方一行，不放侧栏。侧栏只放会话。
  3. 对话排版：头像列加正文，用户消息为带边框的块，助手回复无底色，不用左右气泡。
  4. 检视器：桌面端在右侧推开内容，移动端是整页。运行详情只展示后端或浏览器实际给出的值，未知就写「未知」。
  5. 第一阶段范围：以上均不含批量管理、斜杠命令、模式、模型对比。
